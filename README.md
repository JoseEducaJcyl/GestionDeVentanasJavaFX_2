# GestionDeVentanasJavaFX_2

Proyecto desarrollado en Java utilizando JavaFX y Maven para la gestión de múltiples ventanas y escenas en aplicaciones de escritorio.

## Descripción

Esta aplicación es una continuación de prácticas sobre JavaFX centradas en la gestión de ventanas, permitiendo trabajar con diferentes escenas, navegación entre vistas y control de múltiples interfaces dentro de una misma aplicación.

El proyecto sirve como ejercicio para reforzar la organización de pantallas y la transición entre ventanas en JavaFX.

## Tecnologías utilizadas

- Java
- JavaFX
- Maven

## Requisitos

- JDK 17 o superior
- Maven instalado
- IDE compatible con JavaFX (IntelliJ IDEA, Eclipse o NetBeans)
